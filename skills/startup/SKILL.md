# Startup

## When to use

- When you first launch into a project

Skip this skill if you've been working on this project since first launching.

## Process

1. Read through the directory and understand the project
2. Check what technologies are being used and remember to that so any task only uses compatible technologies.
3. Search through any memory initially so you can get a headstart on understanding 
4. Find patterns that the project uses and note them
5. Just read the project, no updating of anything

## Rules

- Call out any initial issues you might see, perhaps patterns or code areas that are inefficient or could have security issues
- Document any issues you might have in a file so they can be reviewed later
- Do not make any changes
